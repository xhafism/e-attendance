# UI/UX Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the e-attendance app into a premium, modern Glassmorphism & Depth style with a floating top-nav and an emerald green accent color.

**Architecture:** We will replace the current CSS variables with a dark-mode first palette, remove the `<aside className="sidebar">` and `<div className="app-container">` side-by-side flexbox layout, and instead use a floating top navigation bar. The card components and buttons will be updated to use translucent backgrounds and glows.

**Tech Stack:** Next.js App Router, vanilla CSS, Lucide React icons.

## Global Constraints

- **No Tailwind CSS:** This project strictly uses vanilla CSS in `src/app/index.css`.
- **Do not alter DB schema or backend logic:** Only CSS and layout presentation should change.
- **Ensure Responsive Boundaries:** Maintain `min-width: 0` constraints to avoid Safari flexbox bugs.
